# ParallelLingvo

> ParallelLingvo is a multilingual vocabulary learning application for studying Dutch, English and Russian in one connected learning flow.

ParallelLingvo keeps vocabulary, translations, pronunciation and learning progress together. The current application data model supports three languages: Dutch (NL), English (EN), and Russian (RU).

## What ParallelLingvo does

- Organizes vocabulary into lessons.
- Connects one concept with Dutch, English and Russian forms.
- Provides pronunciation audio.
- Lets users mark difficult words for extra review.
- Tracks learning activity and progress at word level.
- Uses a mobile-first web interface and Telegram Mini App access.

## How multilingual learning works

Instead of creating separate bilingual decks, ParallelLingvo organizes vocabulary around one concept. For example, Dutch `ontwikkeling`, English `development`, and Russian `развитие` stay connected in the same learning item.
