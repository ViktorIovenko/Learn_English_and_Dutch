FAQ

About ParallelLingvo

Which languages does ParallelLingvo support?＋

The current application supports Dutch, English and Russian. The same vocabulary item stores the three language versions together.

Can I learn all three languages at the same time?＋

Yes. You can keep Dutch, English and Russian translations connected and choose which direction to practise.

Does it work on mobile?＋

Yes. ParallelLingvo uses a mobile-first web interface and can be opened through Telegram.

How is it different from a normal flashcard app?＋

The main difference is the three-language structure: one concept stays connected across Dutch, English and Russian instead of becoming several duplicated decks.
