FAQ

About ParallelLingvo

Which languages does ParallelLingvo support?＋

The launch catalog contains 45 learning languages: major European languages plus Chinese Mandarin, Japanese, Korean, Arabic, Hindi, Indonesian and Vietnamese. The backend is designed to add more languages later without redesigning vocabulary storage.

Can I learn more than three languages?＋

Yes. Choose three or more supported languages. Translations stay attached to the same vocabulary concept, so you do not need a separate deck for every language pair.

Does it work on mobile?＋

Yes. ParallelLingvo uses a mobile-first web interface and can be opened through Telegram.

How is it different from a normal flashcard app?＋

The main difference is the multilingual structure: one concept can stay connected across several languages instead of becoming many duplicated bilingual decks.
