# Серверное подключение ИИ

Страница: **Админка → ИИ**, `/admin/ai`. Доступ — только через сессию администратора.

Android использует прежние серверные API `/api/translate/word` и `/api/generate/topic`.
Смена модели или инструкций не требует новой версии приложения. Web, Telegram,
MCP и импорты, использующие общий `content_service`, получают тот же адаптер.

## Настройка

1. Введите полный HTTPS URL Chat Completions API совместимого сервиса.
2. Укажите идентификатор общей модели и API-ключ, если сервис требует авторизации.
3. При необходимости задайте модель и дополнительные инструкции отдельно для
   перевода слов, перевода предложений, примеров и подбора темы.
4. Включите подключение и сохраните. Изменения действуют для следующих внешних
   запросов; уже выполняющийся запрос использует свои исходные настройки.

Сохранение не выполняет пробных/платных вызовов. Глобальный
`PAID_AI_ENABLED` и проверки доступа/тарифов продолжают действовать.
Эта страница не включает платный ИИ в окружении автоматически.

До первого сохранения действуют существующие настройки модулей-провайдеров.
После первого сохранения четыре текстовые задачи управляются этой страницей;
выключение подключения не возвращает их к прежнему внешнему провайдеру.
TTS продолжает использовать свою существующую настройку.

## Данные и безопасность

Настройки хранятся в `ai_gateway_settings` в серверной БД. Таблица создаётся
при первом сохранении. API-ключ зашифрован с использованием `Config.SECRET_KEY`;
при переносе БД необходимо сохранять этот серверный секрет. Ключ не возвращается
через страницу или Android API. Пустое поле ключа сохраняет предыдущий ключ;
для удаления есть отдельный флажок. При смене сервиса старый ключ автоматически
не переносится: требуется новый ключ либо явное удаление старого.

Запись защищена проверкой административной сессии, CSRF-токеном и номером
ревизии. Внешние HTTP redirects не выполняются. Ошибки сервиса не раскрывают
его ключ или тело ответа.

Сначала переиспользуется контент из базы. Смена модели не удаляет переводы,
примеры, пользовательские слова или прогресс и не запускает массовую генерацию.
Если у сервиса другой протокол, потребуется серверный адаптер/совместимый шлюз;
Android-контракт остаётся прежним.

Профильная проверка без реальных обращений к ИИ:
`venv/Scripts/python.exe -m unittest tests.test_ai_gateway -q`.
