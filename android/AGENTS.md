# Android scope

Начинай с `../docs/codex/ANDROID_API.md`, затем `ApiService.kt`, DTO и конкретный repository/UI consumer. Сохраняй совместимость URL, HTTP methods, `X-User-Id`/`X-Client`/`X-Device-Language`, DTO defaults, Room/offline queue и backend handler. Не запускай Gradle build/emulator и не загружай APK без отдельного запроса.
